1. static(기본값) vs relative(상대 위치)

relative는 원래 자신이 있던 자리를 기준으로 이동하며, 기존에 차지하던 공간(빈자리)을 그대로 유지합니다. 따라서 주변 요소(박스 3)가 밀려나지 않습니다.

2. relative(부모 기준점) + absolute(자식 배치)

absolute는 문서 흐름에서 완전히 빠져나와 공중에 뜹니다. 부모에게 position: relative를 주어야 부모 상자 안을 기준으로 안전하게 배치됩니다.

4. fixed (브라우저 화면 전체 기준 고정)

부모 요소와 상관없이 브라우저 창(Viewport)을 기준으로 고정됩니다. 현재 화면 우측 하단에 고정된 파란색 [TOP] 버튼을 확인하세요.

5. 정중앙 배치 비교: Position(%) vs Transform(%)

회색 점선은 부모 상자의 정확한 가로/세로 50% 중심선입니다. 두 방식의 위치 차이를 비교해 보세요.

top: 50%; left: 50%;
(좌측 상단 모서리가 중심선에 닿아 치우침)
+ translate(-50%, -50%)
(내 크기의 절반만큼 되돌아가 정중앙 일치)
